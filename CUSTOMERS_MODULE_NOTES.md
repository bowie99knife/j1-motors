# J1 Workshop OS — Polished Customers Module

## Routes
- `/admin/customers`
- `/admin/customers/[id]`

## Included
- Professional customer dashboard and responsive customer cards
- Search by customer, contact details, registration and vehicle
- Customer status filters and sorting
- Add-customer dialog
- Full customer profile with contact details, account summary and preferred contact method
- Linked vehicle cards with direct vehicle profile navigation
- Unified timeline for bookings, jobs, quotes, invoices and notes
- Timeline search and type filters
- Workshop-only notes
- Quick actions for bookings, job cards and quotes
- Realistic demo records

## Packaging checks
- No `public/src`
- No duplicate source tree
- No `.next`
- No `node_modules`

## Local verification
Run:
```bash
npm install
npm run build
```
